# Tic-Tac-Toe Game
## Preview

![Tic-Tac-Toe Game](Screenshot%202026-11-11%20174135.png)


A simple and interactive two-player Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

## Features

- Two-player gameplay (X vs O)
- Automatic player turn switching
- Win detection
- Draw detection
- Scoreboard to track wins and draws
- Highlighting of winning combinations
- Reset button to start a new round
- Responsive user interface

## Technologies Used

- **HTML5** – Structure of the game
- **CSS3** – Styling and layout
- **JavaScript** – Game logic and functionality

## How to Play

1. Player X starts the game.
2. Players take turns selecting an empty cell.
3. The first player to get three symbols in a row, column, or diagonal wins.
4. If all nine cells are filled without a winner, the game ends in a draw.
5. Click the Reset Game button to start another round.

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
